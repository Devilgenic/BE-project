ML Model Algorithm

Convolutional Neural Network (CNN)

The core violence detection model (modelnew.h5) is a Convolutional Neural Network trained using TensorFlow/Keras. CNNs are the state-of-the-art for image classification tasks because they automatically learn spatial hierarchies of features through convolutional layers.

Model Architecture
  • Input Layer: 128 × 128 × 3 (RGB image)
  • Convolutional Layers: Multiple Conv2D layers with ReLU activation extract spatial features (edges, textures, body postures)
  • Pooling Layers: MaxPooling2D reduces spatial dimensions while retaining important features
  • Dense Layers: Fully connected layers for classification
  • Output Layer: Single neuron with sigmoid activation (binary classification: violence / non-violence)
Training Details
  • Dataset: Violence/Non-Violence video frames
  • Preprocessing: Resize to 128×128, BGR→RGB conversion, pixel normalization [0,1]
  • Loss Function: Binary Cross-Entropy
  • Optimizer: Adam optimizer with learning rate scheduling

Multi-Signal Temporal Fusion

A single-frame CNN alone is insufficient for robust violence detection because violence is a temporal event — it involves motion patterns over time. Our system enhances the CNN with two complementary motion analysis signals:

1. Farneback Optical Flow (Weight: 30%)

Computes dense optical flow between consecutive frames using the Gunnar Farneback algorithm. The flow field encodes pixel-level motion vectors.

Score = clip(mean(magnitude) × std(magnitude) / 50, 0, 1)

Violence produces high magnitude + high variance (chaotic, aggressive motion). Normal scenes have low, uniform flow.

2. Motion Energy via Frame Differencing (Weight: 20%)

Computes absolute difference between consecutive grayscale frames, then applies a binary threshold (25) to isolate significant motion regions.

Score = clip(changed_pixels / total_pixels × 3, 0, 1)

Sudden large-area pixel changes indicate fast, aggressive movements characteristic of violence.

3. Weighted Fusion
Fusion = 0.50 × CNN + 0.30 × OpticalFlow + 0.20 × MotionEnergy
4. Exponential Moving Average (EMA) Smoothing
Smoothedt = 0.3 × Fusiont + 0.7 × Smoothedt-1

Reduces noise and single-frame spikes that cause false positives.

5. Sliding Window Evidence Accumulation

A deque of the last 30 analysis results (~3-5 seconds) tracks temporal evidence. Violence is confirmed only when all three conditions are met:

  • Suspicious Ratio > 40%: More than 40% of window frames have fusion score above 0.35
  • Recent Peak > Threshold: At least one of the last 5 frames exceeds the confidence threshold
  • Smoothed Score > 80% of Threshold: The EMA-smoothed score is sufficiently high

This prevents both false positives (single spikes) and false negatives (brief dips between violent frames).
